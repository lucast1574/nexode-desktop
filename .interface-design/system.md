# Nexode Orbit UI

Domain: projects, branches, diffs, working trees, conversations, tool activity.
Color world: charcoal editor surfaces, muted sage metadata, orbital green,
warm white code, red removed lines, green additions.
Signature: original orbital mark, restrained green action, persistent local
runtime status, project context in the composer, adjacent Git review.

Use a quiet coding workspace rather than dashboard metrics, flat layered
surfaces rather than floating cards, and project navigation rather than a
generic application menu. Codex is a reference for information hierarchy,
not a source of logos or copied assets.

- Sidebar 246px; conversation max 820px; optional review pane 360px.
- Canvas #191b19, sidebar #141614, composer #232723, action #10dc79.
- Inter with system fallbacks; 13px base, 36px welcome title, 11px metadata.
- Spacing base 4px; controls radius 6px, composer radius 14px.
- Borders and surface differences establish depth. No focus rings or outlines.
- Focus uses background and text contrast; preserve keyboard navigation.
- Radix menus and dialogs handle arrows, Escape, outside click and focus.
- Lucide SVG icons only; preserve the original Nexode orbital SVG.
- Motion respects reduced-motion automatically. No animation controls.
- Small screens collapse navigation and overlay the review pane.
